## 🌟 About the Project

**Fruit Guide** is a simple yet informative web application that helps users discover everything they need to know about their favorite fruits.

Instead of searching through multiple websites, users can simply enter the name of a fruit and instantly access detailed information, including:

* 🥗 Nutritional values
* 💊 Essential vitamins and minerals
* ✅ Health benefits
* ⚠️ Possible disadvantages or side effects
* 🍽️ Healthy consumption insights

Whether you're a fitness enthusiast, student, nutrition lover, or simply curious about healthy eating, **Fruit Guide** makes learning about fruits fast, fun, and interactive.
